# DATA 690 Lab 6 - Keypoints Detection

## Overview
This project uses MediaPipe and OpenCV on NVIDIA Jetson to detect human body keypoints in real time.

## Features
- Real-time pose detection
- Skeleton keypoints visualization
- Anomaly detection (hands raised above head)
- Simple UI overlay

## Anomaly Definition
An anomaly is detected when the user raises both hands above head level.

python main.py
